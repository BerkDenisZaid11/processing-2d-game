# 2D Enemy Game

## Overview
A 2D game developed using Java and Processing. Enemies move towards a goal, and the player must interact with them to prevent the game from ending.

## Features
- Multiple enemy types
- Enemy movement and collision detection
- Interactive gameplay
- Goal mechanics
- Game-over conditions
- Object-oriented programming using classes
- ArrayList for managing enemies

## Technologies Used
- Java
- Processing

## How to Run
1. Download [Processing](https://processing.org/download).
2. Download this repository to your computer.
3. Open `sketch_2D_game.pde` in Processing.
4. Press the Run button to play.

## Skills Demonstrated
Java programming, object-oriented programming, collections, collision detection, and game logic.
